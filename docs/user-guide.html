1

이 앱은 무엇인가

Web4AI Brand AEO는 AEO(Answer Engine Optimization, 답변 엔진 최적화) 관점에서 브랜드의 가시성을 진단하는 콘솔입니다. 기존 검색엔진 SEO와 달리, ChatGPT·Gemini·Claude·Perplexity 같은 AI 답변 엔진이 내 브랜드를 얼마나 알고 인용하는지를 다룹니다.

측정은 매주 같은 질문을 답변 엔진에 반복해 물어, 브랜드가 언급되는 정도(Share of Mention)·순위·인용 출처를 집계하는 B1–B9 파이프라인으로 이뤄집니다.

데스크톱 앱인 이유

경쟁사·주소 같은 한국 로컬 정보 회상은 실행 리전에 따라 정확도가 크게 달라집니다. 이 데스크톱 앱은 한국에서 Gemini로 직접 측정하도록 만들어져, 클라우드(미국 리전) 대비 국내 브랜드 회상이 정확합니다.

2

설치와 첫 실행

  1. 설치본 내려받기

    GitHub Releases의 최신 버전에서 Web4AI-Brand-AEO-0.1.21-installer.zip을 받습니다. 일부 환경에서 .exe 직접 다운로드가 막히므로 ZIP으로 제공합니다.

  2. 압축 해제 후 설치

    ZIP을 풀면 나오는 설치본(.exe)을 실행합니다. 설치 위치는 바꿀 수 있습니다.

  3. 첫 실행

    처음 실행하면 필요한 데이터(질문 은행·스코어카드 등)가 자동으로 준비됩니다. 측정 데이터는 사용자 폴더(%APPDATA%/brand-aeo-app)에 저장되어 업데이트에도 보존됩니다.

Windows 보안 경고가 뜨면

서명되지 않은 앱이라 SmartScreen 경고가 나올 수 있습니다 — 추가 정보 → 실행으로 진행합니다. Smart App Control(SAC)이 켜져 있으면 우회가 불가하니, 신뢰하는 환경에서 SAC를 끄거나 관리자에게 문의하세요.

4

API 키

측정에는 Gemini API 키가 필요합니다. v0.1.16부터 키가 설치본에 기본 포함되어, 보통은 별도 설정 없이 바로 측정할 수 있습니다. STAGE 1 브랜드·경쟁사 측정 화면 상단에 상태가 표시됩니다.

  • GEMINI 설정됨 표시 — 그대로 사용하면 됩니다. (입력창 없이 상태만 보입니다.)
  • 키를 바꾸려면 "키 변경"을 눌러 입력창을 펼치고, 새 키를 붙여넣어 저장합니다. 키는 이 PC에만 저장됩니다(%APPDATA%/brand-aeo-app/.env).
  • 미설정 상태라면 Google AI Studio에서 발급받아 입력합니다.
Tip

동봉 키의 사용량이 소진되면 측정이 실패할 수 있습니다. 이때 "키 변경"으로 본인 키를 넣으면 즉시 복구됩니다.

5

빠른 시작: 등록 → 측정

가장 핵심적인 흐름입니다. 브랜드를 한 번 등록하면, 이후에는 목록에서 버튼 하나로 측정합니다.

  1. 브랜드 추가 — URL로 자동 채우기

    ＋ 브랜드 추가에서 브랜드 홈페이지 URL을 넣고 URL에서 자동 채우기를 실행하면, 브랜드명·도메인·업종·주소·경쟁사가 자동 추론되어 채워집니다. 결과는 초안이니 직접 검토·수정하세요.

  2. 정보 · 경쟁사 확인 후 등록

    업종·지역·경쟁사를 확인하고 브랜드 등록을 누릅니다. 경쟁사를 넣으면 코호트 순위(1/N) 비교가 가능합니다. 등록하면 상단 브랜드 메뉴에서 바로 선택됩니다.

  3. 전체 측정 시작

    등록 완료 단계의 "이 브랜드 전체 측정 시작" 버튼, 또는 아래 등록된 브랜드 관리 목록의 "전체 측정" 버튼을 누릅니다. 경쟁사·코호트까지 함께 측정합니다(수 분 소요). STAGE 1로 이동하지 않아도 됩니다.

  4. 진행 확인 · 결과 보기

    측정은 서버에서 추적되어, 다른 화면으로 이동해도 유지됩니다. 측정 상태에서 진행을 보고, 완료되면 대시보드 · 랭킹 · 퍼포먼스에 점수가 반영됩니다.

본 브랜드 vs 경쟁사

본 브랜드를 측정하면 경쟁사·코호트까지 함께 채워집니다. 목록에서 특정 경쟁사만 갱신하려면 STAGE 1 브랜드·경쟁사 측정에서 그 경쟁사를 골라 측정합니다.

Site AEO Checker

주간 파이프라인과 별개로, 지금 이 페이지의 HTML을 직접 수집해 즉시 채점하는 단일 URL 진단입니다. 실제 인용·노출·순위를 예측하는 것이 아니라, AI 검색 대응 준비도를 봅니다. aeocheck.co.kr과 동일한 6개 영역·100점 체계를 씁니다.

수집은 JS 렌더링 전 원본 HTML 기준입니다 — JS를 실행하지 않는 AI 크롤러가 보는 상태와 같습니다.

8

브랜드 관리

＋ 브랜드 추가 화면 아래 등록된 브랜드 관리 목록에서 등록한 브랜드를 한눈에 보고 관리합니다.

  • 전체 측정 — 각 브랜드 행의 버튼으로 바로 측정합니다(경쟁사·코호트 포함). STAGE 1로 갈 필요가 없습니다.
  • 삭제 — 데스크톱 앱에서는 즉시 완전 삭제되어 목록·선택 메뉴에서 바로 사라집니다. 이때 다른 브랜드가 참조하지 않는 고아 경쟁사도 함께 정리됩니다(공유 중인 경쟁사는 보존).
참고

배포(웹) 환경에서는 삭제가 GitHub Actions로 커밋 데이터·점수까지 정리하며 수 분이 걸립니다. 데스크톱 앱은 로컬에서 즉시 처리됩니다.

9

자동 업데이트

사이드바 하단에 현재 버전이 표시됩니다. 업데이트 확인을 누르면 새 버전 여부를 확인하고, 있으면 자동으로 내려받습니다.

  • 새 버전이 준비되면 "재시작하여 설치" 버튼이 나타납니다 — 누르면 앱이 재시작되며 설치됩니다.
  • 측정 데이터·등록 브랜드·API 키는 사용자 폴더에 있어 업데이트해도 보존됩니다.
