KT가 단독 1위로 올라섰다, 그런데 언급은 줄었다

KT의 Brand AEO Score는 W39 50점(SK텔레콤과 공동 1위)에서 W40 53점(단독 1위)이 됐다. 점수를 올린 것은 SoM·자사 인용·추천 순위이고, 언급률은 84.1%에서 72.7%로 11.4%p 떨어졌다. W39는 같은 설정으로 두 번, W40은 한 번 쟀다. 두 주 사이에 설정은 바뀌지 않았다. 세 번 모두 같은 방향으로 나온 결과는 SoM 1위와 원리를 묻는 질문 두 개에서의 미언급이고, W40에 처음 나타난 변화는 아직 한 번 측정한 값이다.

정정: 1판은 판정 모델이 인용마다 기록한 도메인 값으로 세어 “대표 도메인 kt.com 비중 12% → 35.1% → 48.8%”, “kt.com 인용 61건 → 125건”으로 적었다. 이 값은 서브도메인 주소 일부가 kt.com으로 묶인 것이었고(묶이는 비율도 주마다 달랐다), 실제 인용 주소의 호스트로 다시 셌다. W39 2차는 판정 기록이 덮어써져 주소 기준으로 다시 셀 수 없다.

KT 쪽에서 사이트를 바꿨는지는 확인하지 않았다. W39 두 번 사이의 흔들림(2%p 안팎)보다 훨씬 큰 차이지만 W40은 한 번 쟀으므로, W41에 같은 방향으로 나오기 전까지는 결론으로 쓰지 않는다. KT 제안서의 핵심 문장(“KT 자료와 경쟁사 자료가 거의 같은 비중”)과 반대 방향이다.

순위표의 결함

고친 것과 남은 것

해결 측정하지 않은 사실성이 100%로 채워지던 문제

통신 5사는 팩트 그래프가 없어 사실성 판정이 거의 0건인데, v0.2.41까지는 판정이 0건이면 100%로 채워져 점수가 부풀었다. v0.2.42에서 사실성을 점수에서 빼고 정확도로 따로 보여 주도록 바꿨다. W39 점수가 SK텔레콤·KT·LG유플러스·LG헬로비전·세종텔레콤 순으로 58·57·55·44·20에서 50·50·47·34·3으로 내려간 것이 이 때문이다. SK텔레콤과 KT가 동점이 된 것 말고는 순서가 그대로다.

해결 같은 주를 다시 재면 전주·이동평균이 틀리던 문제

같은 주를 다시 재면 그 주의 이전 측정 카드를 “전주”로 써 왔다. v0.2.44에서 고쳤고, W40 오후 재측정이 고친 뒤의 첫 실제 사례다. 경쟁 4사 모두 전주가 W39 값으로 맞게 저장됐다(SK텔레콤 전주 50, LG유플러스 47, LG헬로비전 34, 세종텔레콤 3).

해결 리포트 본문의 코호트 순위

v0.2.43에서 리포트 본문에서 확정 전 코호트 순위를 뺐다. KT W40 report.md에는 순위 문구가 없다.

주의 경쟁 3사의 추천 순위가 기준선에 겨우 걸렸다

W40에 순위가 매겨진 응답이 SK텔레콤·LG유플러스·LG헬로비전 모두 딱 3건이다. W39에는 5~10건이었다. 기준(3건 이상)을 겨우 넘겨 계산은 됐지만, SK텔레콤의 1.00위는 응답 3건이 모두 1위였다는 뜻이고 점수에 2.8점을 더했다. SK텔레콤이 언급·SoM·자사 인용에서 모두 조금씩 내려갔는데도 점수가 1점 오른 이유다.

심각 다섯 곳이 서로 다른 시험지를 푼다

브랜드마다 질문 은행을 따로 만들어 일반 질문 22개가 서로 하나도 겹치지 않는다. 점수의 약 59%(언급률·SoM)가 여기서 나오므로, KT 72.7%와 SK텔레콤 82.9%의 차이가 가시성 차이인지 질문 차이인지 가릴 수 없다. 코호트 단위 공유 질문지가 필요하다.

주의 사실성을 볼 수 없다

통신 5사 모두 팩트 그래프가 없어 사실성이 두 주 내내 「판정 불가」다. AI가 KT 요금·혜택을 정확하게 설명하는지는 지금 데이터로 말할 수 없다.

믿을 수 있는 것

반복해서 같은 방향으로 나온 결과

안정 KT는 통신 이야기에서 가장 큰 몫을 가져간다

SoM은 W39 2차 40.5%, 3차 40.8%, W40 50.3%로 세 번 모두 5사 중 1위다. W40에는 2위 SK텔레콤(36.0%)과의 차이가 14%p로 벌어졌다.

재현 원리를 묻는 질문 두 개에서 KT가 빠진다

“인터넷 100M와 500M 체감 차이”, “5G와 LTE 배터리·발열” 두 질문에서 KT는 세 번 연속, 두 엔진 모두에서 한 번도 언급되지 않았다. KT 제안서의 원인 ②가 세 번째로 확인됐다.

확인 필요 W40에 처음 나타난 두 변화

언급률 하락(84.1% → 72.7%)과 자사 인용의 확실한 우위(25.0% 대 16.3%)는 W40 한 번의 측정에서만 나왔다. 둘 다 W39 두 번 사이의 흔들림보다 크지만, W41에 다시 재서 같은 방향인지 확인하기 전까지는 고객용 결론으로 쓰지 않는다.

우선순위

  1. W41 두 번 측정

  2. KT 제안서 핵심 문장 점검

    제안서의 “KT 자료와 경쟁사 자료가 거의 같은 비중”은 W39 두 번에서 나온 결론이라, 5판(W40)에서 세 번 모두 성립하는 “KT를 설명하는 근거의 4분의 3은 KT 밖”으로 바꿨다. 원인 ①은 실제 주소 기준으로 다시 세어 “대표 사이트 www.kt.com 인용 0건”으로 고쳤다. W41에도 자사 인용 우위가 이어지는지 보고 다시 점검한다.

  3. 통신 팩트 그래프 등록

    요금·혜택 팩트 그래프를 등록해야 “AI가 KT를 정확하게 설명하는가”를 잴 수 있다.

  4. 코호트 공유 질문지

    다섯 곳이 같은 일반 질문을 풀어야 언급률 차이를 가시성 차이로 읽을 수 있다. 공유 은행을 도입하면 주차 비교가 한 번 끊기므로 버전 기준을 먼저 정한다.

각 브랜드의 scorecard-history.json(W39–W40)과 raw-calls.json·question-analyses.json에서 읽었다. W39 1·2차 값은 3차로 덮어써지기 전에 기록해 둔 것이고(옛 점수 기준), W40 오전 경쟁 4사 값은 userData/backup-before-same-week-rescore/의 스코어카드에서 읽었다. 점수 기여도와 감성 계수는 server/aggregate.ts로 다시 계산했다. 점수·순위는 2026-09-30 현재 기준(v0.2.41 추천 순위 · v0.2.42 사실성 제외)이다.
